# Разработка и проверка

Нужен Node.js 22 (та же версия используется в CI) и npm.

```bash
npm ci
npm run dev
```

Vite обычно открывается на `http://localhost:5173`, API — на порту 8787. Точный адрес Vite смотрите в выводе: занятый порт может привести к выбору следующего. Прокси `/api` настроен в `vite.config.ts`.

Для отдельного checkout можно собрать приложение и запустить сервер на другом порту:

```bash
npm run build
API_PORT=8788 npm start
```

Этот процесс раздаёт API и `dist` на `http://localhost:8788`. После изменения серверного кода для production-запуска нужны новая сборка и перезапуск. `npm run dev` использует наблюдение за изменениями.

## Проверки

```bash
npm run format:check
npm test
npm run build
```

Сборка включает проверку TypeScript. Доменные тесты проверяют миграцию старого проекта, независимость треков, размещение, геометрию и обязательные комплектующие. HTTP-тест поднимает сервер на свободном порту с большим внедрённым каталогом и проверяет фильтрацию, страницы, ошибки и серверные цены.

Проверка интерфейса против запущенного сервера:

```bash
TEST_URL=http://localhost:8788 npm run check:ui
```

По умолчанию используется `/usr/bin/google-chrome`. Другой Chromium можно указать через `CHROME_PATH`. Сценарии открывают собственный браузерный контекст, не меняют сохранённый проект в браузере разработчика и сохраняют диагностические скриншоты в `/tmp/lights-*.png`. Большой каталог подставляется только в браузерном тесте через перехват запросов; обычное приложение сохраняет небольшой демонстрационный каталог.

## Статическая версия Pages

```bash
VITE_PAGES_DEMO=true GITHUB_PAGES_REPO=lights-configurator npm run build
npm run preview -- --port 5188
```

Путь будет `http://localhost:5188/lights-configurator/`. Workflow `.github/workflows/pages.yml` при push в `main` выполняет форматирование, тесты, сборку и публикацию. README-превью — десктопные снимки реального интерфейса, `preview-3d.png` и `preview.png`.

## Ручные сценарии

- Открыть старый однотрековый JSON и проверить миграцию.
- Выбрать Z-форму: появляются три размера; добавить прибор на нижний участок.
- Перетащить прибор через соседний и на другой участок того же трека; проверить отсутствие пересечений.
- Добавить второй трек, поменять его профиль и удалить прибор с него; первый трек сохраняется.
- Увеличить длину и нагрузку: меняются секции, соединители, крепления и питание.
- Проверить план, 3D, потолок снизу и свободный обзор сверху.
- В большом каталоге использовать поиск, фильтр и страницы; список не растягивает панель.
- Проверить внутреннюю прокрутку спецификации: стоимость и кнопка остаются внизу панели.

Обновить десктопные превью после запуска текущей сборки:

```bash
TEST_URL=http://localhost:8788 npx tsx scripts/capture-previews.ts
```

Скрипт создаёт собственный демонстрационный проект в изолированном браузерном контексте и заменяет оба PNG в корне.
