# Разработка

## Локальный запуск

Нужны Node.js 22 и npm.

```bash
npm ci
npm run dev
```

Команда запускает Vite и API с отслеживанием изменений. Обычно интерфейс доступен на `http://localhost:5173`, API — на порту 8787. Если порт Vite занят, смотрите адрес в терминале. Прокси для `/api` настроен в `vite.config.ts`.

Собранную версию можно запустить отдельно:

```bash
npm run build
API_PORT=8788 npm start
```

Сервер будет отдавать приложение и API на `http://localhost:8788`. Изменения кода здесь требуют новой сборки и перезапуска.

## Проверки

```bash
npm run format:check
npm test
npm run build
```

`npm test` запускает тесты модели, геометрии, комплектации и API. `npm run build` проверяет TypeScript и собирает клиент с сервером. Только проверка типов — `npm run typecheck`.

Для браузерных тестов сначала запустите приложение, затем укажите его адрес:

```bash
TEST_URL=http://localhost:8788 npm run check:ui
```

Скрипт использует `/usr/bin/google-chrome`. Путь к другому Chromium задаётся через `CHROME_PATH`. Тесты работают в отдельном контексте браузера и не затрагивают сохранённый вручную проект. Скриншоты остаются в `/tmp/lights-*.png`.

Большой каталог в этих тестах подставляется через перехват запросов. В самом приложении остаётся обычный тестовый набор товаров.

### Что проверить вручную после изменений интерфейса

- Формы и размеры: у Z-формы три размера; повторный клик по выбранной форме сохраняет настройки.
- Расстановка: светильник можно протащить через соседний и перенести на другой участок, но нельзя оставить поверх другого.
- Несколько треков: изменение и удаление одного не затрагивает остальные.
- Каталоги: поиск, фильтры, страницы и несколько добавлений подряд без закрытия окна.
- Удаление: Delete и Backspace работают на плане, но не удаляют объекты при вводе текста или открытом каталоге.
- Спецификация: состав меняется с длиной и нагрузкой, список прокручивается внутри панели, итог остаётся видимым.
- 3D: потолок виден снизу и не мешает обзору сверху.
- Файлы: сохранение и повторное открытие проекта, в том числе старого формата с одним треком.

## GitHub Pages

Push в `main` запускает `.github/workflows/pages.yml`: форматирование, тесты, сборку и публикацию. В настройках Pages должен быть выбран источник **GitHub Actions**.

Чтобы проверить эту версию локально:

```bash
VITE_PAGES_DEMO=true GITHUB_PAGES_REPO=lights-configurator npm run build
npm run preview -- --port 5188
```

Адрес: `http://localhost:5188/lights-configurator/`. Эта сборка работает без API.

## Превью для README

После запуска актуальной версии:

```bash
TEST_URL=http://localhost:8788 npx tsx scripts/capture-previews.ts
```

Скрипт создаёт проект для снимков в отдельном контексте браузера и заменяет `preview.png` и `preview-3d.png` в корне. Оба снимка — десктопные.
