# Правила обязательной комплектации

Правила принадлежат профилю `TrackProduct.requirements`, а артикулы и цены — `Catalog.accessories`. Разные профили могут ссылаться на разные соединители, заглушки, крепления и питание. Спецификация в UI показывает комплектующие каждого трека, TXT содержит агрегированный заказ.

**Все текущие товары, цены и монтажные нормы демонстрационные.** Они показывают механизм, но не подтверждают совместимость с реальными артикулами ЦЕНТРСВЕТ. Перед коммерческим применением правила нужно заменить и проверить по данным производителя.

## Что учитывается

| Правило        | Расчёт                                                                                       |
| -------------- | -------------------------------------------------------------------------------------------- |
| Секции профиля | Для каждого участка `ceil(длина / unitLength)`, затем сумма                                  |
| `straight`     | Стыки секций внутри каждого участка плюс соединение двух соосных участков                    |
| `end`          | По одной заглушке на свободный конец                                                         |
| `corner`       | Узел из двух неколлинеарных участков                                                         |
| `tee`          | Узел из трёх участков                                                                        |
| `cross`        | Узел из четырёх участков                                                                     |
| `mount`        | Для каждого участка `ceil(длина / spacing) + 1` креплений                                    |
| `power`        | Для каждой связной цепи минимум один БП; далее `ceil(нагрузка × loadFactor / capacityWatts)` |

Граф соединений строится по совпадающим концам участков, а не по названию формы. Поэтому прямоугольник получает четыре угловых соединителя и не получает торцевых заглушек. Параллельные линии образуют две независимые цепи, каждая получает питание. Т-форма и крест имеют собственные соединители.

Демонстрационный накладной профиль использует шаг крепления 0,6 м, встроенный — 0,5 м и другой артикул крепления. Блок питания — 100 Вт, резерв мощности — 20%. Суммарная мощность берётся из выбранных светильников, а не из яркости предпросмотра.

## Допущения прототипа

Обрезки профиля между участками не переиспользуются. Крепления на концах соседних участков считаются отдельно. Разводка питания, длина кабеля, число вводов, ограничения на ток и максимальную длину электрической цепи не моделируются. При превышении мощности правило добавляет БП, но не проектирует электрическое разделение цепи. Это нужно уточнить у производителя до выпуска монтажной спецификации.

В текущих формах узлы всегда заданы концами отдельных участков. Произвольные пересечения без узла и углы вне готовых шаблонов не поддерживаются. Приборы имеют зазор 8 см между соседями, 2 см от границы доступного участка и дополнительный отступ 12 см у концов участков составных форм, чтобы не занимать соединения.

## Как добавить правило или профиль

1. Добавить аксессуар с постоянным ID и ценой. Для БП указать `capacityWatts`.
2. В профиль добавить `requirements`: `accessoryId`, `rule` и при необходимости `spacing` / `loadFactor`.
3. Указать `unitLength` и `layoutIds`, которые профиль действительно поддерживает.
4. Добавить тесты для реальных комбинаций: короткий/длинный участок, угол, ветвление, замкнутый контур и переход через предел мощности.

Новый алгоритм правила добавляется в `domain/trackRequirements.ts`. Проверки текущих правил находятся в `tests/geometry.test.ts`.
