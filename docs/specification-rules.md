# Расчёт комплектации

У каждого профиля есть `TrackProduct.requirements` — правила подбора деталей. Сами детали и цены лежат в `Catalog.accessories`. Поэтому у накладного и встроенного профиля могут быть разные крепления, соединители и питание.

В интерфейсе детали показаны отдельно для каждого трека. В TXT одинаковые позиции объединяются в общий заказ.

Текущие правила и цены тестовые. Для реального заказа их нужно сверить с каталогом производителя: совместимость с артикулами ЦЕНТРСВЕТ пока не проверена.

## Как считаются детали

| Деталь / правило                | Расчёт                                                                                 |
| ------------------------------- | -------------------------------------------------------------------------------------- |
| Секции профиля                  | `ceil(длина / unitLength)` для каждого участка, затем сумма                            |
| Прямой соединитель (`straight`) | Стыки секций внутри участка и соединения двух участков на одной прямой                 |
| Заглушка (`end`)                | По одной на свободный конец                                                            |
| Угловой соединитель (`corner`)  | На соединение двух участков под углом                                                  |
| Т-соединитель (`tee`)           | На соединение трёх участков                                                            |
| Крестовой соединитель (`cross`) | На соединение четырёх участков                                                         |
| Крепление (`mount`)             | `ceil(длина / spacing) + 1` на каждый участок                                          |
| Блок питания (`power`)          | `ceil(нагрузка × loadFactor / capacityWatts)` на каждую соединённую цепь, минимум один |

Соединения определяются по совпадающим концам участков. Например, у прямоугольника четыре угловых соединителя и нет заглушек. У двух параллельных линий отдельное питание для каждой.

В тестовом каталоге:

- шаг креплений — 0,6 м для накладного профиля и 0,5 м для встроенного;
- мощность блока питания — 100 Вт, запас — 20%;
- зазор между светильниками — 8 см;
- отступ от края доступного участка — 2 см;
- у составных форм ещё по 12 см с каждого конца участка отводится под соединения.

Нагрузка считается по мощности выбранных светильников. Ползунок яркости в предпросмотре на подбор питания не влияет.

## Что пока не учитывается

Обрезки профиля не используются на других участках. Крепления на концах соседних участков считаются отдельно.

Расчёт добавляет блоки питания по нагрузке, но не разбивает цепь на электрические группы. Кабели, вводы, предельный ток и максимальная длина цепи тоже пока не рассчитываются. Без этих данных спецификация не подходит для монтажа.

Формы состоят из готовых участков с соединениями на концах. Произвольные пересечения и углы за пределами шаблонов не поддерживаются.

## Добавление профиля

1. Добавьте детали в `Catalog.accessories`: ID, название и цену. Для блока питания также нужен `capacityWatts`.
2. В `requirements` профиля укажите `accessoryId` и `rule`. Для креплений можно задать `spacing`, для питания — `loadFactor`.
3. Задайте длину секции `unitLength` и допустимые формы `layoutIds`.
4. Проверьте комплектацию на коротком и длинном треке, углах и ветвлениях, замкнутом контуре и при превышении мощности одного БП.

Код расчёта находится в `domain/trackRequirements.ts`, тесты — в `tests/geometry.test.ts`. Если существующих правил не хватает, новое правило нужно добавить туда.
