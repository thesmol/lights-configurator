# Конфигуратор трекового освещения

[Live demo](https://thesmol.github.io/lights-configurator/)

Прототип для подбора треков и светильников. Можно задать размеры комнаты, собрать несколько треков, расставить свет на плане и посмотреть результат в 3D. Спецификация и цена пересчитываются при изменениях.

Сделан на React, TypeScript, Tailwind CSS и Three.js. Данные приходят из REST API на Node.js. В версии для GitHub Pages каталог и расчёт работают в браузере.

Каталог небольшой, цены и правила комплектации тестовые. Освещение в 3D даёт представление о результате; для расчёта освещённости оно не подходит. Интерфейс рассчитан прежде всего на десктоп.

## Запуск

Нужны Node.js 22 и npm.

```bash
npm ci
npm run dev
```

Приложение — `http://localhost:5173`, API — `http://localhost:8787`. Если порт Vite занят, актуальный адрес будет в терминале.

Для запуска собранной версии:

```bash
npm run build
npm start
```

Она откроется на `http://localhost:8787`.

## Что можно попробовать

- Выбрать одну из восьми форм трека и настроить её размеры.
- Добавить светильники из каталога и перетащить их на свободные места в плане.
- Добавить второй трек с отдельными настройками.
- Посмотреть комнату с разных сторон, в том числе снизу на потолок.
- Скачать спецификацию или сохранить проект в JSON.

Проект также сохраняется в браузере автоматически.
